HeatWhisper — Flash

  1. Wire power only (leave the pump RS485 disconnected for now). Waveshare ESP32-S3 RS485-CAN: USB-C for flashing, 7–36V screw terminals for running, 120Ω jumper ON for a single-drop bus.
  2. Flash: plug in via USB, click Install, pick the port. The manifest picks ESP32 vs ESP32-S3 automatically. Use https://<user>.github.io/heat-whisper/ or python3 -m http.server locally (WebSerial needs HTTPS or localhost, Chrome/Edge).
  3. Wi-Fi: after flashing, click Configure Wi-Fi in the Install dialog (Improv over USB). Skipped it? Join the fallback AP HeatWhisper (password heatwhisper01) and pick your network in the captive portal.
  4. Connect the pump: wire pump A/B to the onboard screw terminals, power up. The bridge autodetects the NIBE model from its announcement — no model setting, no Modbus vs NIBE choice.
  5. Pump menu 5.2 (service menu, hold Back 7s): Modbus OFF, enable only RMU S2, leave RMU S1 OFF so BT50 keeps working. Check http://<node>/heatwhisper/registers for Pump is polling S2 (live) vs not polled yet (5.2 checkbox missing).
  6. Home Assistant: Settings → Devices & Services → ESPHome — the node appears automatically (no API key on factory image). Click Add.
  7. Pick registers (optional): open http://<node>/heatwhisper/registers, check what to expose (18 defaults, max 50), save, reboot.

Pico W (no WebSerial — RP2040 not supported by ESP Web Tools)

  1. Download heatwhisper_pico_w.uf2 from the latest GitHub Release.
  2. Hold BOOTSEL, plug in USB, drop the .uf2 onto the mass-storage drive.
  3. Join Wi-Fi via fallback AP HeatWhisper + captive portal, then add in HA as above.

Advanced: Modbus-RTU (MODBUS40 accessory, Lambda/Thermia/…) needs no recompile — open http://<node>/heatwhisper/registers, pick the model under Modbus-RTU setup, Detect & save, reboot. Troubleshooting: no values → check wiring/A-B swap, then open http://<node> logs; writes ignored below addr 20000 is by design.

Beta testers: flash from /beta/ or download .ota.bin from the latest -beta pre-release.
