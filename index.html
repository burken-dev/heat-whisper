HeatWhisper — Flash

ESP32 / ESP32-S3 (WebSerial: Chrome/Edge)

ESP32-S3 RS485-CAN: same Install button — the manifest picks the matching build automatically. Wire pump A/B to the onboard screw terminals, power 7–36V, 120Ω jumper ON for a single-drop bus.

Plug in via USB, click Install, pick the port. Use index.html from https://<user>.github.io/heat-whisper/ or python3 -m http.server locally (WebSerial needs HTTPS or localhost).

Pico W (no WebSerial — RP2040 not supported by ESP Web Tools)

  1. Download heatwhisper_pico_w.uf2 from the latest GitHub Release.
  2. Hold BOOTSEL, plug in USB, drop the .uf2 onto the mass-storage drive.

First boot: join Wi-Fi via fallback AP HeatWhisper + captive portal, or pre-fill secrets.yaml. Bring-up: flash with passive: true first, confirm decode on web_server :80, then re-flash with TX enabled.
